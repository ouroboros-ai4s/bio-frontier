# OpenAI GPT-6 蛋白质设计研究的总结

> 以下四条 conclusion 总结自 [[2026-11-27-openai-gpt6-intrinsic-protein-design-experiments]] 和 [[2026-11-28-reactions-to-openai-gpt6-protein-design]].

1. **通用模型有望补足专用模型的能力缺口**: GPT-6.2 在多种蛋白设计任务中理解不同约束并提出了候选. 一个值得验证的 hypothesis 是, 通用模型能借助更广泛的知识和推理能力, 处理专用模型训练较少覆盖的任务.

2. **训练数据隔离程度和实验任务难度仍待核实**: 未公开骨架和明显不同的新序列削弱了直接复述原序列的解释, 但训练数据里是否存在相似序列或结构, 公开资料还无法判断. 有限的可比基线也让任务难度难以定位. (本条 conclusion 截至 2026.11.28)

3. **湿实验命中率反映的是筛选后候选的表现**: GPT-6.2 负责提出设计, 专用模型在部分实验中参与序列生成, 并参与候选筛选. 论文以实际送检的候选为分母.

4. **研发价值取决于能否更快或更省地找到有用分子**: 湿实验支持部分候选在测试条件下能够结合靶蛋白. 候选是否具备所需的生物学功能, 以及这套流程能否缩短整个项目周期或降低总成本, 仍需分别验证. 如果项目主要卡在实验和验证环节, 设计提速对整体周期的影响可能有限.
