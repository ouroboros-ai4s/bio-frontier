# OpenAI GPT-6 蛋白质设计研究的推论

> 以下 inference 推理自 [[2026-11-28-conclusions-on-openai-gpt6-protein-design]].

通用模型最大的潜在节省, 可能来自算力基础设施和运维. 如果未来 GPT 等通用智能能在设计质量和吞吐量相当的条件下, 替代目前需要大量 GPU 算力的专用模型, 团队就可以把原先依赖自备服务器的计算工作转为按量付费的 API 调用. 算力由服务商提供, 团队可以省下购置和维护 GPU 服务器、部署和更新多套专用模型的成本. 这笔账要按获得一个合格候选的总成本来算, 把批量生成和重试的 token 费用也计入.
